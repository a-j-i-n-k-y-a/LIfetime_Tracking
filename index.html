Phases of your life

Chapters marked as age ranges — they shade the gutter beside the chart in every view, and the legend below it reports how each one went. Ranges run from the first age up to but not including the last, so 20–23 covers ages 20, 21 and 22. Gaps are fine, and overlaps go to the earlier phase.

Sync across devices Off

Keeps your laptop and phone on the same log, using a private GitHub Gist as the store. Edits made on either device — even offline — are merged, never overwritten.

Open the gist
Creating the token
  1. Open Fine-grained personal access tokens → Generate new token.
  2. Name it anything. Set an expiry you're happy to renew.
  3. Leave repository access alone — this needs none.
  4. Under Account permissions, set Gists to Read and write. Nothing else.
  5. Generate, copy the github_pat_… value, paste it above.

The token is stored in this browser's local storage so it survives a reload. Anyone with access to this device, or to this page through a scripting bug, could read it — and it can read and write all of your gists, not just this one. Use a fine-grained token with an expiry, keep it off shared machines, and revoke it from GitHub settings if you stop using the app. Your token is never written to the gist.

Without sync, everything stays in this browser's local storage and nothing leaves the device. Export/Import JSON moves a log between devices by hand; imports merge rather than replace, so they're safe in either direction.
